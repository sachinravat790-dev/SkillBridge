SkillBridge AI — Frontend Prototype
===================================

Files:
- index.html: complete HTML + CSS + JavaScript frontend.

How to preview:
1. Open index.html in Chrome, or
2. Upload/paste the contents into Base44 as a design and workflow reference.

Included interactions:
- Sidebar navigation
- Student profile editing and skill chips
- Four-question technical quiz with scoring
- Demo job matching cards
- Company demo role creation
- Learning roadmap checkboxes and progress updates
- Responsive layout for desktop and mobile

Important:
- This is a frontend-only prototype using sample data.
- No real authentication, database, AI API, or live job listings are connected.
- Data is held in JavaScript memory and resets on page refresh.
